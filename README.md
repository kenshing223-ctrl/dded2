# dded2

Classic Snake built with plain HTML/CSS/JavaScript.

## Run locally

```bash
npm test
npm start
```

Then open `http://localhost:4173`.

## Controls

- Arrow keys or `WASD` to steer.
- `Space` to pause/resume.
- `Restart` button to reset after game over (or any time).
- On small screens, use the on-screen direction buttons.

## Manual verification checklist

- [ ] Snake moves one cell at a time on a fixed interval.
- [ ] Snake grows and score increments after eating food.
- [ ] Snake dies when hitting walls or its own body.
- [ ] Restart resets snake, score, and food.
- [ ] Pause/resume works with Space key.
- [ ] Keyboard and on-screen controls both steer the snake.
